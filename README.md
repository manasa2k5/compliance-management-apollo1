# 🚀 Compliance Management System (CMS)

A full-stack MERN application designed to streamline compliance task management, reporting, and workflow automation for organizations. The system enables role-based access, real-time tracking, and automated notifications to ensure timely completion of tasks.

---

## 🌐 Live Demo

* 🔗 Frontend: https://compliance-management-apollo1.onrender.com
* 🔗 Backend API: https://apollo-backend-8hp4.onrender.com

---

## 🔥 Key Features

* 🔐 Role-Based Access Control (Super Admin, Department Admin, Executive)
* ✅ Task Creation, Assignment & Status Tracking
* 📅 Calendar View for Deadline Management
* 🔔 Automated Email Notifications for Overdue Tasks
* 📊 Interactive Dashboard with Reports (Pie & Bar Charts)
* 📄 PDF Report Generation
* 🧾 Audit Logs to track user activity
* 🔍 Advanced Filtering (Department, Category, Date, Keywords)
* 📎 File Upload Support (with size limits)
